# GitHub Translator

一个面向 GitHub 网页的浏览器翻译扩展，目标是让 GitHub 的界面、README 和讨论内容更适合中文阅读。

当前版本采用混合翻译模式：

1. 模块名、按钮、状态词等短界面文本使用本地词典翻译。
2. README、Issue、Pull Request、评论正文等长文本默认使用 LM Studio 本地接口进行 AI 翻译。

## 当前接入边界

当前版本**不提供官方云端翻译服务，也不会默认把内容发送到开发者自有服务器**。

扩展里的所有 AI 请求都只会发往用户自己配置的 `API Base URL`，也就是：

- 你本机的 LM Studio / Ollama / 其他本地 OpenAI 兼容接口
- 你自己选择并填写的第三方模型 API

如果用户不填写自己的接口，扩展不会自动转发到任何“官方远端”。

## 适合什么场景

- 想把 GitHub 常见界面按钮和模块名快速翻成中文
- 想阅读英文 README、Issue、PR 说明，但又不想离开 GitHub 页面
- 想在本机用 LM Studio 本地模型完成翻译，而不是依赖在线接口
- 想保留 GitHub 原本的页面观感，不希望翻译结果太突兀

## 当前能力

1. 自动把 GitHub 常见模块名、按钮、状态词和菜单翻译成中文。
2. 顶部仓库功能按钮旁可显示简要功能说明。
3. 支持手动调用 AI 翻译当前页中的 README、Issue、PR 和评论正文。
4. AI 翻译结果支持 Markdown 渲染，并尽量贴近 GitHub 原生文档风格。
5. 页面右侧提供始终悬浮的操作面板，方便边看边翻译、边调整设置。
6. 支持手动重新应用界面翻译或恢复原文。

## 翻译策略

### 1. 本地词典翻译

适用于：

- 仓库顶部导航模块
- 页面按钮
- 状态词
- 菜单项
- 常见 GitHub 术语

优点：

- 快
- 稳定
- 不依赖网络或模型接口

### 2. AI 正文翻译

适用于：

- README
- Issue 正文
- Pull Request 正文
- 评论区内容
- 仓库简介等较长文本

特点：

- 尽量保留 Markdown 结构
- 优先生成更自然的中文技术文档语气
- 默认走 LM Studio 本地 OpenAI 兼容接口

## 项目结构

- `manifest.json`: Chrome/Edge 扩展配置
- `content.js`: GitHub 页面内的本地词典翻译和正文翻译入口
- `background.js`: 调用本地 AI 接口完成长文本翻译
- `popup.html` / `popup.js` / `popup.css`: 扩展弹窗设置页

## 页面内操作面板

当前版本会在 GitHub 页面右侧注入一个悬浮操作板，方便直接操作：

- 启用或关闭界面词典翻译
- 重新应用界面翻译
- 触发 AI 翻译当前页正文
- 恢复页面原文
- 编辑 `API Base URL`、`Model`、`API Key`

这里的 `API Base URL` 始终表示**用户自己控制的接口地址**，不是本项目提供的公共云端地址。

## LM Studio 本地使用

1. 安装并打开 LM Studio。
2. 下载 `Qwen2.5-1.5B-Instruct` 的 GGUF 版本模型。
3. 在 LM Studio 中启动本地 OpenAI 兼容接口。
4. 默认接口地址为：

```text
http://127.0.0.1:1234/v1
```

5. 打开扩展弹窗，确认以下默认配置：
   - `API Base URL`: `http://127.0.0.1:1234/v1`
   - `Model`: `qwen2.5-1.5b-instruct`
   - `API Key`: 留空即可

## 本地安装

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页，例如 `chrome://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前项目目录。
6. 打开 GitHub 页面并刷新一次，让内容脚本注入生效。

## 使用方法

1. 打开任意 GitHub 页面。
2. 通过扩展弹窗或页面右侧悬浮操作板配置模型参数。
3. 启用界面词典翻译后，GitHub 常见按钮和模块会自动变成中文。
4. 点击“AI 翻译 README / 正文”可翻译当前页长文本。
5. 如果想恢复英文原文，可以点击“恢复页面”。

## 当前推荐配置

- `API Base URL`: `http://127.0.0.1:1234/v1`
- `Model`: `qwen2.5-1.5b-instruct`
- `API Key`: 留空

如果你后面换成更强的本地模型，也可以直接替换 `Model`。

如果你想改用其他在线模型服务，也需要由你自己填写对应的 OpenAI 兼容接口地址和密钥；项目本身不附带公共远端服务。

## 当前限制

1. 本地词典部分的准确度取决于 GitHub 术语覆盖率，需要持续补充。
2. AI 正文翻译依赖你本机 LM Studio 服务正常运行，或依赖你自行配置的第三方模型接口。
3. GitHub 页面更新后，可能会出现新的英文词条需要再适配。
