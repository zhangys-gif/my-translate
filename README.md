# GitHub Translator

一个面向 GitHub 网页的浏览器翻译扩展 MVP，目标是帮你更顺手地浏览 GitHub。

当前版本是纯本地词典翻译版，不调用任何 AI 接口。

## 当前能力

1. 自动把 GitHub 常见界面元素翻译成中文。
2. 支持对常见状态词、按钮、菜单和部分提示语做本地替换。
3. 支持手动重新应用翻译或恢复原文。

## 项目结构

- `manifest.json`: Chrome/Edge 扩展配置
- `content.js`: GitHub 页面内的本地词典翻译逻辑
- `popup.html` / `popup.js` / `popup.css`: 扩展弹窗设置页

## 本地安装

1. 打开 Chrome 或 Edge。
2. 进入扩展管理页，例如 `chrome://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前项目目录。

## 使用方法

1. 打开任意 GitHub 页面。
2. 点击扩展图标。
3. 勾选“启用 GitHub 界面翻译”。
4. 点击“保存设置”。
5. 如果当前页已经打开，可以点击“立即应用到当前页”。
6. 如果想恢复英文原文，可以点击“恢复页面”。

## 当前限制

1. 它更适合 GitHub 界面汉化，而不是长段自然语言翻译。
2. 术语准确度取决于词典覆盖率，需要持续补充。
3. GitHub 页面更新后，可能会出现新的英文词条需要再适配。

## 下一步适合增强的方向

1. 增加更完整的 GitHub 术语词典。
2. 按页面类型拆分词典，例如仓库页、Issue 页、PR 页、个人主页。
3. 增加用户自定义术语表。
4. 增加“鼠标悬停显示原文”的对照模式。
